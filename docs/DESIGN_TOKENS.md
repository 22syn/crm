# hadaryaCRM Design Tokens

Extracted from `designs/hadarya-design-system.pen`. Use these for CSS variables and Tailwind config.

## Colors

| Token | Value | Usage |
|-------|-------|-------|
| `--primary` | `220 20% 25%` (HSL) | Primary text, dark elements |
| `--secondary` | `220 20% 95%` (HSL) | Secondary backgrounds |
| `--accent-action` | `262 55% 50%` (HSL) | Primary CTAs, accent |
| `--success` | `142 65% 42%` (HSL) | Success states |
| `--sidebar` | `#0f1025` | Sidebar background |

### Component fills (from design)

- Primary button: `hsl(262, 55%, 50%)`
- Secondary button: `hsl(220, 20%, 95%)` + border `hsl(220, 15%, 90%)`
- Card: `hsl(220, 15%, 99%)` + border `hsl(220, 15%, 90%)`
- Input field: `#ffffff` + border `hsl(220, 15%, 90%)`
- Badge: `hsl(220, 20%, 95%)`
