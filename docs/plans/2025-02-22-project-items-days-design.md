# עיצוב: פריטי פרויקט – כמות + מספר ימים

**תאריך:** 22 בפברואר 2025  
**סטטוס:** מאושר  
**הקשר:** חידוד מודול משרד פרסום – הוספת שדה ימים לחישוב עלות פריט.

---

## 1. מה משתנה

**מחיר בקטלוג (op_items):** תמיד **מחיר ליום**.

**פריט בפרויקט (op_project_items):** מוסיפים שדה **`days`** (מספר ימים).

**חישוב עלות לפריט:**
```
סך שורה = item.price × quantity × days
```

**דוגמה:** צלם ₪1,000/יום, כמות 2, 3 ימים → 1,000 × 2 × 3 = ₪6,000

---

## 2. שינויים במודל

### op_project_items (עדכון)

| שדה | תיאור |
|-----|--------|
| project_id | הפרויקט |
| item_id | הפריט מהקטלוג |
| quantity | כמות |
| **days** | **מספר ימים** (חדש, NUMERIC או INTEGER) |

---

## 3. שינויים ב־UI

- **דיאלוג "הוסף פריט לפרויקט":** שדה "מספר ימים" (חובה).
- **טבלת פריטים בפרויקט:** עמודות: סוג, כמות, ימים, מחיר ליום, סך שורה.
- **חישוב:** `total = item.price × quantity × days` (ללא עיגול מיוחד).

---

## 4. Migration

מיגרציה חדשה: `ALTER TABLE op_project_items ADD COLUMN days NUMERIC NOT NULL DEFAULT 1` (או INTEGER). עדכון נתונים קיימים: `days = 1` לפריטים ישנים.
